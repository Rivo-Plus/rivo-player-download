## 🍏 التثبيت على الماك

1. اضغط زر التحميل وانتظر انتهاء التحميل، ثم افتح الملف `RivoPlusPlayer-mac-….dmg` من مجلد التنزيلات.
2. ستظهر نافذة فيها سهم: **اسحب أيقونة Rivo+ Player إلى مجلد Applications**.
3. افتح التطبيق من Launchpad أو من مجلد Applications.
4. **أول مرة فقط:** إذا قال الماك إنه لا يستطيع التحقق من التطبيق، اضغط **تم**، ثم افتح
   **إعدادات النظام ← الخصوصية والأمان**، وانزل للأسفل واضغط **فتح على أي حال**، ثم أكّد بكلمة سر الماك.
5. إذا ظهرت رسالة أن التطبيق «تالف»: افتح تطبيق **Terminal** والصق هذا السطر ثم اضغط Enter، وبعدها افتح التطبيق مرة أخرى:

   ```
   xattr -cr "/Applications/Rivo+ Player.app"
   ```

## 🪟 التثبيت على ويندوز

1. اضغط زر ويندوز وافتح الملف `RivoPlusPlayer-Windows-Setup.exe`.
2. إذا ظهر **Windows protected your PC**: اضغط **More info** ثم **Run anyway**.
3. التثبيت يتم تلقائيًا بضغطة واحدة ويفتح التطبيق مباشرة، وتجد اختصارًا على سطح المكتب.

## 🇬🇧 Install (English)

**Mac:** open the downloaded `.dmg` → drag **Rivo+ Player** onto **Applications** → open it. First launch only: System Settings → Privacy & Security → **Open Anyway**.
**Windows:** run `RivoPlusPlayer-Windows-Setup.exe` (if SmartScreen appears: More info → Run anyway). It installs in one click and starts.
Then: **Add your first playlist → Xtream Codes** and enter the login we sent you.
